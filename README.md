# Онлайн-тест (frontend + backend)

Node.js + Express + SQLite. Студенты регистрируются и проходят тест, администратор входит в свой аккаунт и видит результаты (можно скачать CSV и сбросить попытку).

## Запуск локально
```bash
npm install
cp .env.example .env        # впишите JWT_SECRET
npm run create-admin -- admin МойПароль123   # создать администратора
npm start                   # http://localhost:3000
```

## Вопросы теста
Редактируйте `questions.json` (перезапуск не нужен). Формат вопроса:
```json
{
  "id": "q3",
  "text": "Найдите A·B",
  "matrices": [ {"label": "A", "data": [[1,2],[3,4]]}, {"label": "B", "data": [[2,0],[1,2]]} ],
  "options": [ [[4,4],[10,8]], [[2,0],[3,8]], "не определено" ],
  "correct": 0
}
```
- `matrices` — необязательно; показываются в условии.
- Вариант ответа — либо текст/число, либо матрица (массив массивов).
- `correct` — номер правильного варианта (с нуля). Клиенту он не отправляется.
- `id` должен быть уникальным и не меняться после начала тестирования.

## Доступ из разных сетей
Нужен публичный хостинг с HTTPS: Render, Railway, Fly.io или свой VPS.
1. Загрузите репозиторий на хостинг, команда запуска: `npm start`.
2. Переменные окружения: `JWT_SECRET`, `COOKIE_SECURE=true`, `DATA_DIR` (путь к **постоянному диску**, иначе база SQLite потеряется при перезапуске).
3. Создайте администратора командой `npm run create-admin -- логин пароль` в консоли хостинга.
4. Отправляйте студентам ссылку на сайт.

## Роли
- `student` — регистрируется сам (отключить: `ALLOW_REGISTRATION=false`), проходит тест один раз.
- `admin` — только через `create-admin`; видит все результаты.
